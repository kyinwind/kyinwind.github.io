Welcome to the MichaelDev Help Center.

This site is the public support home for all apps built under MichaelDev. It is not only for VideoHero: the goal is to make every app easier to understand, try, and troubleshoot across its supported platforms.

## Apps covered here

- [VideoHero](/help/videohero/) — PPT-to-video assistant for narrated slide videos on desktop.
- [RightClickMate](/help/rightclickmate/) — practical right-click tools for desktop file workflows.
- [TTSMate](/help/ttsmate/) — text-to-speech utility for voiceover files, with a cross-platform roadmap.
- DayDayUp — daily quote and growth companion.
- 功课助手, 诵经助手, 念佛助手, 拜忏助手 — quiet practice apps.

## Current documentation status

VideoHero, RightClickMate, and TTSMate now have mirrored help docs from their Feishu knowledge bases.

The Chinese help center also includes the initial SongJing Assistant docs. Other practice apps will be added as their support materials are organized.

## Where to start

If you are exploring the apps, start from the [MichaelDev home page](/).

If you already know which app you need help with, choose it from the sidebar.

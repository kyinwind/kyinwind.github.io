- **Format Conversion** is used to quickly convert common image, audio, and video files in Finder — no need to open professional editing software.
- Select files via right-click menu to convert images such as **JPG, HEIC, WEBP, SVG** to **PNG or JPG**, **WAV, AIFF, MP3, M4A** audio to other formats, extract **MP3 audio from MP4**, or convert **MP4 to GIF**.
- This feature supports batch processing of files in the same format. Results can be saved to the original folder, a **Converted** folder, or a custom folder of your choice.
- When encountering duplicate filenames, you can also choose to auto-rename or overwrite. The conversion process displays progress and completion status.

## Supported Format Conversions

| Category | Source Format | Convert To | Description |
|-|-|-|-|
| Image | SVG | PNG | Convert vector images to common raster format |
| Image | JPG / JPEG | PNG | Preserve original pixel dimensions |
| Image | HEIC | PNG, JPG | For better compatibility across more devices and platforms |
| Image | WEBP | PNG | Improve image format compatibility |
| Image | PNG | JPG | Ideal for uploading, sharing, or reducing file size |
| Audio | WAV | MP3, M4A | Convert to compressed formats better suited for storage and playback |
| Audio | AIFF / AIF | MP3, M4A | Convert lossless audio to commonly used compressed formats |
| Audio | MP3 | WAV | Convert to uncompressed audio format |
| Audio | WMA | MP3 | Convert WMA audio to high-quality MP3 |
| Audio | M4A | WAV | Convert to uncompressed audio format |
| Video | MP4 | MP3 | Extract audio from video |
| Video | MP4 | GIF | Convert video to animated GIF |
| Video | MOV | MP4 | Convert Apple MOV videos to MP4 |
| Video | AVI | MP4 | Convert AVI format videos to MP4 |
| Document | PDF | DOCX | Convert PDF files to Word documents |
| Document | PDF | PPTX | Convert PDF files to PowerPoint presentations |

- Copy to Folder

## Applicable to:

Classifying and organizing downloaded files.

For example, some files go to the backup directory, some to the work directory, some to the study directory, or life directory.

## Operation steps:

1. Select multiple files or directories, right-click, and select the 'Copy to...' menu.
2. In the pop-up submenu, select the target path and click.

After successful copying, the target directory where the files were copied will be displayed.

If you cannot find the target directory you want to copy to in the target directory, there are two ways:

### Method 1: In the submenu, select 'Copy to...'

A dialog will appear for you to select the target folder.

After confirming, this directory will be recorded and will appear below the target directory in the future.

### Method 2: On the Mac desktop top menu bar, select the RightClickMate icon.

Click 'Directory Permissions'.

Then the directory permissions settings page appears. Here, click the 'Add' button, which will pop up a folder selection window. After selecting the specified folder, a directory naming window will appear. Modify and click 'Confirm' to save this directory.

Directories created with Method 2 will appear in the upper part of the 'Copy to...' menu.

# RightClickMate - Make Right-Click More Efficient

RightClickMate is a right-click enhancement tool for macOS Finder and Windows. It helps you complete more frequent file operations from the interface you already use every day, without switching apps or learning complex shortcuts.

It focuses on one goal: making every right-click more valuable.

[RightClickMate Feature Overview](/help/rightclickmate/feature-overview/)

[Release Notes](/help/rightclickmate/release-notes/)

# Target Users

### Mac & Windows Users

RightClickMate provides quick file actions, folder management, batch renaming, and other tools to improve the efficiency of the right-click menu on Mac and Windows.

### Content Creators & Bloggers

For content creators who often work with images, screenshots, and videos, RightClickMate provides useful tools such as Privacy Eraser, Batch Resize Images, Quick Image Annotation, and Format Conversion.

Feel free to share what features you would like to see in the right-click menu.

title: "Favorite Folders"
description: "RightClickMate technical support and help center."
---
**Favorite Folders** lets you quickly open folders you use often, reducing the need to browse through Finder level by level.

You can add folders in Settings and customize their display names. You can also add the current folder to Favorite Folders directly from the Finder right-click menu.

**Method 1:** Open Settings and click Add.

**Method 2:** Add the current folder to Favorite Folders from the right-click menu.

After adding folders, right-click and choose **Open Folder** to quickly open a target folder from the submenu.

![Favorite Folders screenshot](/help-assets/rightclickmate/en/favorite-folders/favorite-folders-03.png)

RightClickMate also shows recently accessed folders based on your usage, making it easier to return to frequently used work folders, project folders, or file storage locations.

Folder permissions are saved through the macOS security authorization mechanism. You can view, open, or remove them from Settings at any time.

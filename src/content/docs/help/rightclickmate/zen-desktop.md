**Zen Desktop (Screen Recording / Presentation Mode)**

## Applicable to:

1. When screenshots or screen recording is needed, but the desktop is too cluttered and needs to be covered.
2. When presenting or projecting, need to cover the desktop and have a timer.

## Operation steps:

1. Right-click on the desktop or in a folder.

Select 'Zen Desktop'.

At this time, the desktop will be covered by a blurred image. The original icons and widgets will be blurred, but the running app interfaces will not be covered.

1. Right-click and select 'Add Countdown', enter the number of minutes to add.

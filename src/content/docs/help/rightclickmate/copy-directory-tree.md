- Copy Directory Tree

## Applicable to:

Developers need to copy their folder directory tree to communicate with AI models to verify if their project architecture is correct.

Right-click on a folder, select 'Copy Directory Tree', and further choose 'Copy Directory Tree' or 'Copy Directory Tree (Directories Only)'

- Copy Directory Tree

Copy the folder and file names below it

- Copy Directory Tree (Directories Only)

Copy folders only

## Note:

Free users support copying directory trees up to 5 levels

Pro users support copying directory trees up to 20 levels

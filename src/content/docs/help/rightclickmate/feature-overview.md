**RightClickMate - Make Right-Click More Efficient**

RightClickMate is a right-click enhancement toolkit designed for everyday macOS and Windows users, as well as content creators.

It helps you complete more frequent file operations from the interface you already know, without switching apps or learning extra shortcuts.

It focuses on one goal: making every right-click more valuable.

# Core Features

**1. Quick New File**

Create common file types such as Word, Excel, PowerPoint, TXT, and more based on templates you set in advance. New files no longer have to start as empty files.

**2. Favorite Folders**

Add the current folder to Favorite Folders from the right-click menu, then open frequently used folders directly from the right-click menu later.

**3. Quick Apps**

Add frequently used apps to the right-click menu so you can launch them faster from files, folders, or the current location.

**4. Copy or Move Files to a Specified Folder**

Preset common backup or archive destinations, then copy or move files with one click to keep file management faster and more organized.

**5. Batch Rename Files**

Use flexible renaming rules to process many files at once and make complex file organization easier.

**6. Copy Path**

Quickly copy the full path of the current file or folder for development, debugging, documentation, or everyday office work.

**7. Open Terminal Here (macOS only)**

Open a Terminal window in the current folder without manually typing the `cd` command.

**8. Batch Resize Images**

Resize selected images in batches for design, content creation, asset organization, and other image workflows.

**9. Privacy Eraser**

Protect private information in images with manual masking, OCR-based detection, and AI repair for masked areas.

**10. Quick Image Annotation**

Save frequently used annotation combinations as templates, then add repeated annotation groups with one click.

**11. Compression / Extraction**

Compress files to ZIP and extract ZIP files from the right-click menu.

**12. Format Conversion**

Convert common image, audio, and selected video formats from Finder.

**13. Zen Desktop (macOS only)**

Quickly enter a clean desktop mode for screenshots and screen recordings.

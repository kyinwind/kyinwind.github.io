- Batch Resize Images

For personal image bloggers and content creators, you often need to submit images to various websites. Some websites have fixed requirements for image dimensions (for example, some app stores have mandatory dimension requirements when submitting apps). In this case, you need a convenient way to modify image dimensions.

Select multiple image files with the mouse, right-click.

Enter the image resize window.

Enter the target dimensions here, and click 'Confirm Resize' to batch resize the images.

You can keep a history of dimensions, and next time you can directly click a historical dimension to automatically copy the width and height values to the target dimensions.

Note:

1. Dimension modification does not consider maintaining the original aspect ratio; it directly modifies according to the entered target dimensions.
2. Supported image file types: jpg, png, tiff, bmp, gif

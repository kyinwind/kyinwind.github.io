**Quick Apps** lets you add frequently used apps to the Finder right-click menu, helping you launch apps or process the current file more quickly.

After setup, you can right-click a file, folder, or blank area in Finder and choose the target app from the **Quick Apps** menu, without going to the Applications folder.

Some apps that support folder arguments, such as Visual Studio Code or terminal tools, can directly open the current folder. This is useful when you want to quickly enter a project directory, edit files, or start command-line work.

You can freely add, manage, or remove Quick Apps in Settings.

The Quick Apps menu is mainly based on apps you manually add. These apps are shown at the top of the menu.

RightClickMate also includes a recent app history list, with up to 20 items. Duplicate apps are automatically removed.

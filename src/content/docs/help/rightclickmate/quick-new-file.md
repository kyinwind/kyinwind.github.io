**Quick New File**

When right-clicking the menu, select 'New File' to see the list of available file types.

There are two types of file types: user-defined file types are in the upper part of the list, and built-in file types are in the lower part, mainly office-related documents.

You can add custom file types if you have the following needs:

1. The built-in file types do not include the file type you want.

For example, developers may need to create Python files or XML files.

For example, designers may need to create XML files or XMind files.

1. You have company-defined document templates in your work, such as PPT templates or Word templates.

To do this, select the RightClickMate icon on the Mac top menu bar and click 'New'.

For Pro users, you can add custom file types in the New File interface, so you can use custom templates when creating new files.

When creating a new file type, if you do not select a template file, it will default to creating a text file.

If you select a template file, the new file will be a copy of the template file.

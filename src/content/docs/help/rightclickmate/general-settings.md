## Three Core Directory Permissions

This section authorizes access to three commonly used directories. The purpose is to obtain access permissions for these directories. In the right-click menu, 'Copy to' and 'Open Directory', as well as 'Copy Directory Tree', all require this access permission.

After authorization, the app can perform operations like copying files, opening directories, and copying directory trees on these directories.

Summary: The above three directories are an initial permission set obtained by RightClickMate, so that users can normally use some basic functions of RightClickMate, such as 'Open Directory' and 'Copy (files) to' menu functions.

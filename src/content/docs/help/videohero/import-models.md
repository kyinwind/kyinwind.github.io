How to Import Models

Why can’t the models be downloaded, or why are they downloading very slowly?

Answer: some models are hosted on Hugging Face. This website can usually be accessed normally outside China, but access from mainland China may be unstable or slow.

## Download Method 1: Baidu Netdisk

Shared file: ModelLibrary.zip

Link: https://pan.baidu.com/s/14rkjNqzN5iJ1jXNPCtukLA?pwd=mdqs

Extraction code: mdqs

![How to Import Models screenshot](/help-assets/videohero/en/import-models/import-models-01.png)

After unzipping:

![How to Import Models screenshot](/help-assets/videohero/en/import-models/import-models-02.png)

Step 2: launch the app. On the Settings page, find the Model Settings section and click “Open Model Library”.

The model location will be shown:

![How to Import Models screenshot](/help-assets/videohero/en/import-models/import-models-03.png)

Go to the downloaded model zip file, unzip it first, then right-click the extracted ModelLibrary folder and copy it.

Paste it into the model directory. When prompted whether to overwrite, confirm the replacement.

![How to Import Models screenshot](/help-assets/videohero/en/import-models/import-models-04.png)

Then close the app and reopen it.

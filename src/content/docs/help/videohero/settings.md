---
title: "Settings"
description: "App-level settings in VideoHero."
---
The Settings window contains general app-level options for VideoHero. It is separate from the project setup page used when creating a PPT-to-video project.

There are four sections in the Settings window: Purchase, General, More Apps, and About.

## Purchase

The Purchase page shows the Pro upgrade for VideoHero. Pro is a one-time purchase with lifetime access. This page also shows your current purchase status and includes a Restore Purchase option, which can be used to sync the purchase status for the current Apple ID.

## General

The General page contains basic app preferences.

- Launch at Login: automatically start VideoHero when you log in to macOS.
- Display Language: choose the interface language. You can follow the system language, use Simplified Chinese, or use English.

## More Apps

The More Apps page recommends other useful apps from the same developer. Each recommendation includes a short introduction and an App Store button, so you can view the app directly in the Mac App Store or App Store.

## About

The About page shows basic information about VideoHero, including the app icon, app name, version number, and a short description. It also provides entries for version history, statement, and feedback.

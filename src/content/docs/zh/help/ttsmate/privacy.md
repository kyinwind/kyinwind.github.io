TTSMate 是一款面向 macOS 的文字转语音应用。本隐私政策说明您使用本 App 时，TTSMate 如何处理相关信息。

## 本地处理

当您使用 Apple TTS、Qwen3-TTS、MOSS-TTS 或 Kokoro TTS 等本地语音引擎时，文本、生成音频、发音字典、音色设置和项目数据均在您的 Mac 本地处理或保存。TTSMate 不会将这些内容上传到开发者服务器。

App 只会访问您通过 macOS 主动选择或授权的文件和文件夹。生成音频会保存在您选择的本地位置，直至您将其删除。

## Azure 语音服务处理

Azure 文字转语音是一项可选的云端引擎。如果您选择 Azure TTS，提交用于语音合成的文本或 SSML 会使用您提供的 Azure 凭据和区域直接发送给 Microsoft Azure 语音服务。Microsoft 会依据适用于您 Azure 账户的条款与隐私政策处理这些内容并生成语音。

TTSMate 不会把您的 Azure 密钥发送给开发者。您填写的密钥和区域会保存在 macOS 钥匙串中。有关 Microsoft 的信息处理方式，请参阅 [Microsoft 隐私声明](https://privacy.microsoft.com/zh-cn/privacystatement)。

## 我们收集的信息

TTSMate 不要求注册账户，不使用广告 SDK，也不进行跨 App 跟踪。开发者不会收集您的合成文本、生成音频、Azure 凭据或银行卡及支付账户信息。

如果您主动联系技术支持或提交反馈，开发者会收到您自愿提供的内容。为了帮助定位问题，反馈还可能包含 App 向您展示的技术信息，例如 App 版本和基本系统信息。请勿在反馈中填写机密或敏感内容。

## App 内购买

App 内购买由 Apple 通过 StoreKit 与 App Store 处理。Apple 负责账单和支付信息处理；TTSMate 仅接收解锁已购买功能所需的交易及权益状态。Apple 对信息的处理受 [Apple 隐私政策](https://www.apple.com/legal/privacy/cn/) 约束。

## 模型下载与外部链接

当您主动下载本地 AI 模型时，TTSMate 可能连接第三方模型或软件托管服务。这些服务可能依据各自的隐私政策接收 IP 地址、请求元数据等标准网络连接信息。下载模型时，您的合成文本和生成音频不会被发送给这些服务。

当您打开帮助、隐私政策、开源许可、App Store 或订阅管理链接时，浏览器会连接相应网站；相关网站会依据其隐私政策处理网络连接信息。

## 信息共享与保留

开发者不会出售您的个人信息。只有在您主动选择云端语音引擎、使用涉及 Apple 或外部服务的功能、提出支持请求，或法律要求时，相关信息才会被传输。

TTSMate 设置、凭据、发音字典、生成音频和项目数据保存在您的设备本地或 macOS 钥匙串中。您可以通过 App、访达或“钥匙串访问”将其移除。您主动发送的支持信息只会在回复请求、保留必要支持记录及履行法律义务所需的合理期限内保存。

## 儿童隐私

TTSMate 并非面向儿童设计，开发者不会故意收集儿童的个人信息。

## 政策变更

当 TTSMate 功能或法律义务发生变化时，本政策可能会更新。最新版本及生效日期将发布在本页面。

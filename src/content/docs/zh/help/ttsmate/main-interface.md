说明：

1.TTS Mate 中所有付费功能及高级功能仅通过 Apple 的 App 内购买进行解锁，功能解锁状态完全基于 App Store 的购买凭证，不依赖任何外部机制和其他第三方云服务是否开启。

2.您购买TTSMate的pro功能与Azure key无关，购买Pro功能并不意味就有了Azure TTS key。

您购买了TTSMate的pro产品，意味着您可以使用发音字典和对话模式的高级功能来批量进行语音转换，而Azure TTS 的key则需要您独自按照Azure平台的要求注册获取，这和本app的Pro功能不是一回事。

3.请确保您理解TTSMate Pro 版的含义和Azure的TTS key的作用。

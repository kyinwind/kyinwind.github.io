# 当前 Word 导入逻辑的要求

App 目前只支持标准 `.docx` 文件。

如果是其他格式的文档，请将文档转为.docx格式。

### 理想文档格式

建议用户这样制作 Word：

```text
第一章 章节标题        ← 使用 Word 内置“标题 1”
第一段正文内容……      ← 使用“正文”或“普通”样式
第二段正文内容……

第二章 章节标题        ← 使用 Word 内置“标题 1”
正文内容……
```

具体要求：

- 文件必须是标准 `.docx`，不要把 `.doc` 直接修改扩展名为 `.docx`。
- 不要使用加密或密码保护的 Word。
- 章节标题应使用 Word 内置的“标题 1”样式。
- 正文使用“正文”或“普通”段落样式。
- 每个标题后至少需要有一段非空正文。
- 第一段正文前应先有一个有效标题，否则标题之前的文字会被丢弃。
- 建议只用“标题 1”表示需要转换的章节。
- 不建议把主要内容放在图片、扫描件、页眉、页脚、批注、脚注、尾注、文本框中。
- 尽量避免用表格组织主要正文，虽然部分表格文字可能被读到，但顺序和结构不够可靠。
- 导入后只保留纯文本，字体、颜色、字号、图片等排版不会保留。

### 标题识别的限制（存在多级标题）

当前代码只识别样式名称完全等于以下内容的标题：

- `Heading 1` / `标题 1`
- `Heading 2` / `标题 2`
- `Heading 3` / `标题 3`

如果文档内容较多，必须要有二级标题或者三级标题，那么建议尽量把正文都放到三级标题，避免某个章节的正文在二级标题下，而某个章节的正文在三级标题下。

以下情况可能无法识别：

- 用户只是把文字加粗、放大，但没有应用 Word 标题样式。
- 使用了“章节标题”“大标题”等自定义样式。
- WPS 或其他软件导出的文档修改了标题样式名称。
- 标题通过大纲级别设置，但没有实际使用标题样式。

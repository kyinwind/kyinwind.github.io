# 主要功能

## 功能概述

app主要功能如下：

1、功课

提供发愿、功课管理功能。帮助佛友通过发愿建立功课计划，并记录佛友功课完成情况，督促佛友每日完成功课，精进修行。

2、诵经

共内置40多种常见经书，供广大佛子诵经学习。

3、善书

共内置佛学相关的善书若干种，供佛友自主学习。

4、拜忏

可自定义拜忏次数、引导词，设定好以后，由app发声引导拜忏。

5、开示

可以显示高僧大德的开示语录，供佛友学习。

目前仅在苹果手机、Mac、iPad上可以以小组件形式显示开示语录。

### 功课首页

在首页可以查看正在进行中的“发愿”以及首页下方的当月功课日历一览表，并可以在历史发愿中查看过往的“发愿”。对于过往的功课记录，还可以通过“功课统计”查看统计详情。

### 电子木鱼（念佛计数）

![首页 screenshot](/help-assets/songjing/zh/index/index-30.png)

在电子木鱼界面，可以自动敲打木鱼，时间间隔也可以自定义设置，例如我一般念佛号是设置为1秒间隔，念地藏王菩萨圣号或观世音菩萨圣号则会设置1.2秒间隔，佛友们可以根据自己的习惯设置，设置好时间间隔后，点击“开始”按钮即可以开始电子木鱼的自动敲打。

对于初学佛，念佛的佛友，念佛最怕的，不是不会念，而是坐下来东想西想——刚念了两句，念头就跑远了。

历代祖师对此早有体会，也留下了很多帮助摄心的方法。其中最实用、最适合我们普通人的，就是印光大师传下来的**十念法**。

这个方法说起来很简单：每念一句佛号，心里默记一个数字，从一数到十，再从头开始。关键在于——**心要记得清、嘴要念得清、耳朵也要听得清**，三者都摄在这一句佛号上，妄念自然无处落脚。具体怎么记？印光大师教了一个窍门：把十句分成**三截来记**——三句一组，再三句一组，后四句一组。这样不容易数乱，也不容易走神。如果杂念还是多，也可以先分成两段：一至五、六至十，等心稳了再回到整十循环。

这不是谁编出来的理论，而是印光大师自己几十年实修出来的经验。它的出处，就是《大势至菩萨念佛圆通章》里那句著名的八个字——**「都摄六根，净念相继」**。

换句话说：把眼耳鼻舌身意都收回来，安住在这一声佛号上，念念相续，不令间断。

十念法不挑人，尤其适合刚开始念佛、心还定不下来的同修。

本次「电子木鱼」加入了印光大师推荐的**十念记数法**。方法很简单：为避免数乱，大师教我们把十句分作三截——前三声为一组，再三声为一组，后四声为一组，总共十声。

这三组木鱼声音做了一定的区别，以配合念佛人的十念计数。

记数不出声，只用心记，让心、口、耳三者都摄在一句佛号之上。如此一句顶一句，妄念便无处落脚，念佛自然容易摄心入定。

现在，无论你在「念佛助手」里专修，还是在「功课助手」中记录每日功课，都能跟着电子木鱼的节奏，用印光大师的方法，把十念念得清清楚楚、稳稳当当。

为了方便佛友，同时也提供了自定义十念法的管理界面，用户可以新增自己习惯的其他十念法，例如2-2-2-4的十念法。

方法虽然不同，但是目的都是一个，就是口念心听，念清楚、听清楚、记数清楚。

## 诵经净念相继

![首页 screenshot](/help-assets/songjing/zh/index/index-38.png)

佛友们在诵经时经常杂念纷飞，所以app提供了一个净念相继的按钮，如果当前页面在念诵时基本无杂念，则可以通过点击“净念相继”按钮翻页，这样一部经书诵完后就可以知道多少页基本上做到了净念相继，下一次再诵此经根据净念相继的页数可以评估自己诵经的进步情况。

此按钮默认关闭，在设置页面可以设定打开。

- 格式转换
- “格式转换”用于在 Finder 中快速转换常见的图片、音频和视频文件，无需打开专业编辑软件。
- 选中文件并通过右键菜单即可将 JPG、HEIC、WEBP、SVG 等图片转换为 PNG 或 JPG，将 WAV、AIFF、MP3、M4A 等音频转换为所需格式，还支持从 MP4 中提取 MP3 音频或将 MP4 转换为 GIF。
- 该功能支持同格式文件批量处理，并可将结果保存到原目录、`Converted` 文件夹或自选目录；
- 遇到同名文件时，还可以选择自动重命名或覆盖。转换过程会显示处理进度和完成结果。

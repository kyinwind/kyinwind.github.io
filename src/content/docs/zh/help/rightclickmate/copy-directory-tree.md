- 复制目录树

适用于：

开发人员需要复制自己的文件夹目录树，来与大模型沟通，以确定自己的项目架构是否正确的时候，会用到此功能。

在文件夹上点击右键，选择“复制目录树”，进一步选择“复制目录树”或“复制目录树（仅目录）”

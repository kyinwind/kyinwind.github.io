- 批量调整图片尺寸

个人图文博主，内容生产者，平时需要在网站提交各种图片，有的网站对图片尺寸有固定要求（例如一些App的应用商店提交应用会对尺寸做强制要求），这时候就需要方便的修改图片尺寸。

用鼠标选择多个图片文件点击右键

![批量调整图片尺寸 screenshot](/help-assets/rightclickmate/zh/batch-resize-images/batch-resize-images-01.png)

进入修改图片尺寸的窗口

![批量调整图片尺寸 screenshot](/help-assets/rightclickmate/zh/batch-resize-images/batch-resize-images-02.png)

在这里输入目标尺寸，点击“确认修改尺寸”按钮可以批量修改图片尺寸。

可以保留历史尺寸，下次使用时可以直接点击历史尺寸，即可自动复制宽高数值到目标尺寸。

注意：

1、尺寸修改不考虑保持原有比例，直接按照输入的目标尺寸进行修改

2、支持图片文件类型 jpg、png、tiff、bmp、gif
